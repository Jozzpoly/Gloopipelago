## Owner product result — FAIL

The richer M4 geography and presentation produce more visible local structure, but organisms still occupy essentially one behavioral archetype:

`find digestible food -> move toward it / wander -> consume -> metabolize -> reproduce -> die`

- efficiency;

## Current-best diagnosis

**The main bottleneck is genotype-to-life expressivity, not mutation amplitude, population count, world size or rendering.**

A small genome can still be the right long-term direction, but only if genes map through a richer developmental/embodied system. The target architecture to investigate is:

`small inherited genotype`
`-> development / phenotype`
`-> embodied capacities + trade-offs`
`-> lifetime-acquired state / memory / plasticity`
`-> action selection`
`-> persistent environmental modification`
`-> changed ecological opportunities and pressures`
`-> selection / co-evolution`

Inherited capacity and acquired lifetime state must remain conceptually distinct. Do not encode learned world facts directly into genes merely to make agents look smarter.
